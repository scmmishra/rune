# Rune documentation

These documents specify how Rune behaves. They describe what the code does today, not plans.

- [Spaces and setups](spaces.md): what a window shows, and where its configuration is stored.
- [Layout](layout.md): how columns, cards, and the hub are arranged, sized, and moved.
- [Cards](cards.md): the card file format, what a source prints, and what an item can do.
- [Agent control](agent-control.md): the MCP server that lets an agent act on the window it runs in.

The terms used here are defined in the Glossary section of [AGENTS.md](../AGENTS.md).
